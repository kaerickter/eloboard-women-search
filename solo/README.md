# 이아깽 후원기록 (무료 Render 통합)

기존 서버 한 대의 `/solo/` 경로에서 동작합니다. 별도 Render 서비스나 유료 리소스는 생성하지 않습니다. 홈 화면에 `이아깽 후원기록` 링크를 추가했습니다. 기록 화면, 조회/백업 API, 감시 설정은 모두 기존 `SPAWN_DIARY_ADMIN_PASSWORD`로 인증해야 접근할 수 있습니다. 비밀번호를 코드나 브라우저 저장소에 보관하지 않습니다. 로그인은 12시간 유효하며 서버 재시작 시 다시 로그인합니다.

SOOP 이아깽(2ahgo1203) 방송을 30초마다 감시합니다. 일반 별풍선, 도전미션 참여/상태/정산, 대결미션 후원을 구분합니다. 대결 후원은 일반+도전 정산 합계와 별도입니다. 로그인하지 않아도 서버가 실행 중이면 수집합니다. 기존 `DATABASE_URL`을 사용하되 `solo_archive` 스키마만 추가하고 기존 테이블을 수정하지 않습니다. Neon에 바로 저장하며 재시작 후 기존 회차를 이어갑니다. 방송 중에는 단일 수집기 임대 잠금으로 배포 중 중복 연결을 줄입니다.

최근 90일이 기본 조회 기간입니다. 원본 보존 지침에 따라 이전 기록을 자동 삭제하지 않습니다. 일반 채팅과 인증 티켓은 저장하지 않습니다. 화면은 5초마다 확인하되 변경 없는 응답은 304로 보내고 큰 응답은 압축합니다. 숨겨진 탭은 자동 조회하지 않습니다. 방송 대기 상태 확인만으로는 DB를 계속 깨우지 않습니다.

GitHub 공개 저장소의 표준 Linux 실행기로 10분마다 `/solo/healthz`를 확인하는 예약 작업을 포함합니다. 예약은 지연되거나 누락될 수 있고, 장기간 저장소 활동이 없으면 비활성화될 수 있습니다. 따라서 무료 환경의 무중단 수집을 보장하지 않습니다. 이 경로는 기록이나 비밀번호를 노출하지 않으며 Neon을 조회하지 않습니다.

Render 무료 한도: 워크스페이스 전체 월 750 실행시간, Hobby 월 5GB 외부 전송량, 이 계정 월 500 빌드분. 31일에 서버 한 대는 744시간입니다. 다른 무료 서버 실행시간도 합산됩니다. 15분 외부 요청이 없으면 절전되고, 다시 요청하면 기동됩니다. 무료 서버는 언제든 재시작될 수 있고 로컬 파일은 영구 저장소가 아닙니다. 결제수단이 등록된 계정은 전송량 초과 시 추가요금이 생길 수 있습니다. 이 변경은 요금제를 올리지 않지만 계정 전체 초과요금까지 차단하는 기능은 아닙니다. Neon 무료 저장/컴퓨팅 한도도 별도입니다.

기존 PC 수집 기록을 자동으로 복사하거나 합산하지 않습니다. 연결 중단 구간의 후원 소급 복구는 지원하지 않습니다. 실제 SOOP 선물 발생 시 수신 검증은 별도로 필요합니다.
