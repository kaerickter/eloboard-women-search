# 이아깽 방송기록 (무료 Render 통합)

## 사용량 알림·합방·예시 미리보기

`RENDER_API_KEY`는 Render 서버 환경변수에서만 읽습니다. 6시간마다 Render API로 이 워크스페이스 서비스들의 월 전송량을 조회하고, 한국 날짜별 전송량 및 최근 최대 7개 완료 일자의 일간 평균으로 월말 예상치를 계산합니다. 사용량은 청구 대시보드와 집계 지연·반올림 차이가 있을 수 있습니다. API 조회가 실패하면 수치를 안전하다고 표시하지 않고 확인 필요로 표시합니다. 월간 과금 집계 경계는 UTC, 일간 표시는 한국 시간입니다.

누적 80% 또는 월말 예상 초과 시 경고하고, 누적 90%부터 이 기록실의 자동·수동 합방 수집을 함께 일시정지합니다. 기존 사이트 전체를 중지하거나 계정 초과 과금을 차단하는 기능은 아닙니다. 이 버튼으로 유료 요금제로 전환되는 것을 차단할 수 있다고 안내하지 않습니다. 무료 실행시간·빌드시간과 Neon 사용량은 이 전송량 지표와 별개입니다.

GitHub 공개 저장소 표준 실행기가 6시간 간격으로 일반적인 경고 상태만 확인합니다. 경고 또는 위험 단계별로 월 1개의 Issue를 만들고 저장소 소유자를 할당해 GitHub 알림을 보냅니다. 실제 사용량 수치·후원자 기록·API 키는 공개 Issue에 넣지 않습니다. 이메일 수신 여부는 사용자 GitHub 알림 설정에 따릅니다. `/solo/usage-notice`는 상태 단계만 반환하고 실제 사용량 API는 로그인으로 보호됩니다.

합방은 SOOP 생방송 또는 방송국 주소로 최대 3개를 수동 등록할 수 있습니다. 현재 방송 번호를 확인하고 해당 회차만 수집하며 종료/다음 회차 감지 시 중지합니다. 방송 진행자의 전체 후원 기록이며 이아깽 개인 몫을 자동 판별하지 않습니다. 기존 기록을 지우지 않고 `sessions.bj_id`, `sessions.source` 열과 별도 수동 등록 테이블만 추가합니다.

`/solo/?preview=1`은 가상 데이터로 본인 방송과 합방 회차·후원자·미션 기록을 보여줍니다. 실제 기록에 쓰지 않으며 수집 변경·다운로드 버튼을 비활성화합니다. 예시 합계는 일반 3,500 + 도전 정산 1,200 + 대결 획득 2,177 + 애드벌룬 100 = 6,977개, 대결 후원 별도 500개입니다.

기존 서버 한 대의 `/solo/` 경로에서 동작합니다. 별도 Render 서비스나 유료 리소스는 생성하지 않습니다. 홈 화면에 `이아깽 방송기록` 링크를 추가했습니다. 기록 화면, 조회/백업 API, 감시 설정은 모두 기존 `SPAWN_DIARY_ADMIN_PASSWORD`로 인증해야 접근할 수 있습니다. 비밀번호를 코드나 브라우저 저장소에 보관하지 않습니다. 로그인은 12시간 유효하며 서버 재시작 시 다시 로그인합니다.

SOOP 이아깽(2ahgo1203) 방송을 30초마다 감시합니다. 일반 별풍선, 도전미션 참여/상태/정산, 대결미션 후원을 구분합니다. 대결 후원은 별도이며, 실제 대결 획득 정산액만 일반+도전 정산 합계에 더합니다. 로그인하지 않아도 서버가 실행 중이면 수집합니다. 기존 `DATABASE_URL`을 사용하되 `solo_archive` 스키마만 추가하고 기존 테이블을 수정하지 않습니다. Neon에 바로 저장하며 재시작 후 기존 회차를 이어갑니다. 방송 중에는 단일 수집기 임대 잠금으로 배포 중 중복 연결을 줄입니다.

최근 90일이 기본 조회 기간입니다. 원본 보존 지침에 따라 이전 기록을 자동 삭제하지 않습니다. 일반 채팅과 인증 티켓은 저장하지 않습니다. 화면은 5초마다 확인하되 변경 없는 응답은 304로 보내고 큰 응답은 압축합니다. 숨겨진 탭은 자동 조회하지 않습니다. 방송 대기 상태 확인만으로는 DB를 계속 깨우지 않습니다.

GitHub 공개 저장소의 표준 Linux 실행기로 5분마다 `/solo/healthz`를 확인하는 예약 작업을 포함합니다. 예약은 지연되거나 누락될 수 있고, 장기간 저장소 활동이 없으면 비활성화될 수 있습니다. 따라서 무료 환경의 무중단 수집을 보장하지 않습니다. 이 경로는 기록이나 비밀번호를 노출하지 않으며 Neon을 조회하지 않습니다.

Render 무료 한도: 워크스페이스 전체 월 750 실행시간, Hobby 월 5GB 외부 전송량, 이 계정 월 500 빌드분. 31일에 서버 한 대는 744시간입니다. 다른 무료 서버 실행시간도 합산됩니다. 15분 외부 요청이 없으면 절전되고, 다시 요청하면 기동됩니다. 무료 서버는 언제든 재시작될 수 있고 로컬 파일은 영구 저장소가 아닙니다. 결제수단이 등록된 계정은 전송량 초과 시 추가요금이 생길 수 있습니다. 이 변경은 요금제를 올리지 않지만 계정 전체 초과요금까지 차단하는 기능은 아닙니다. Neon 무료 저장/컴퓨팅 한도도 별도입니다.

기존 PC 수집 기록을 자동으로 복사하거나 합산하지 않습니다. 연결 중단 구간의 후원 소급 복구는 지원하지 않습니다. 실제 SOOP 선물 발생 시 수신 검증은 별도로 필요합니다.

Hobby API 지표의 보관 기간은 7일이므로 시간별 지표를 Neon에 누적해 월간 합계를 유지합니다. 첫 달은 기존 과금 화면의 반올림된 사용량과 관측 시각을 서버 환경변수 SOLO_BASELINE_MONTH / SOLO_BASELINE_BYTES / SOLO_BASELINE_AT로 등록합니다. 기준값은 해당 월에만 적용하고 기존 저장값을 덮어쓰지 않습니다. 이후 월은 누적 지표로 계산합니다. 이는 지연을 포함하는 추정치이며 청구 한도 차단 장치가 아닙니다.

대결미션은 SVC_MISSION(121)의 GIFT(후원)와 SETTLE(실제 획득)를 구분합니다. SETTLE의 settle_count를 회차별 battleEarnedTotal과 정산 합계에 반영하고 후원자에게 임의 배분하지 않습니다. uuid 또는 미션 key로 재전송을 중복 제거합니다. 이전 버전에서 저장하지 않은 SETTLE은 소급 복구할 수 없습니다. 공식 플레이어 LivePlayer.js의 setBattleMission과 LiveView.js의 mission_settle 표시를 근거로 구현했으며, 실제 생방송 정산 수신 확인은 별도로 필요합니다.

애드벌룬은 공식 플레이어 SVC_ADCON_EFFECT(87)의 bjID/userID/userNickname/adcon_cnt 필드를 사용합니다. 대상 BJ ID와 양의 정수 개수를 확인하고 live commerce 알림(title 있음)은 제외합니다. 별도 adballoon 이벤트를 보관해 일반 별풍선과 분리 표시하며 스트리머·후원자 합계와 TXT에 더합니다. 유효한 패킷 UUID가 있으면 중복 저장을 막고, 식별자가 없는 동일 금액의 별도 후원을 임의로 제거하지 않습니다. 과거 미수집 내역은 소급 복원하지 않습니다.
